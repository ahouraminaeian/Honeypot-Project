# Honeypot-Project
Demonstrates risks of insecure networks by deploying a honeypot VM in Azure to monitor unauthorized logins, map attacker geolocations, and analyze exploitation speed.
The project includes 5 parts which include Azure setup, simulating and capturing attacks, log centralization and SIEM integration, IP geolocation, and creating an attack map using Sentinel Workbook.
While the pdf version of the project can be viewed in Github due to its smaller size compared to the word document, The word document version of the project includes downloadable documents created and used in creating the watchlist, logging, and mapping out the attackers.
